---
name: Mobile navigation on wide screens
description: User intent for bottom navigation across phone and wider browser screens.
---

Keep the bottom navigation looking mobile even when the app is opened on a wider screen.

**Why:** the user requested this after showing a wide-screen view where the tabs
spread across the browser while the page content stayed in a centered column.

**How to apply:** keep bottom navigation aligned with the mobile-width content
instead of spreading its tabs across the available desktop width.
